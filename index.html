Organizador de Mods

Análisis local de metadatos + verificación por hash en Modrinth/CurseForge cuando hace falta.

ℹ️ Primero se lee fabric.mod.json / mods.toml / mcmod.info dentro de cada .jar. Si no queda claro, se calcula el hash del archivo y se intenta identificar automáticamente en Modrinth (sin clave) y, si diste tu clave, en CurseForge. Cada mod que quede "Por clasificar" incluye además un buscador que consulta Modrinth solo por el nombre clave del mod (sin número de versión, versión de Minecraft ni loader) para evitar resultados ruidosos; puedes revisar los resultados y confirmar el correcto con un clic. Si las peticiones automáticas quedan bloqueadas por el visor donde abriste esta página, cada tarjeta deja enlaces para verificar manualmente en una pestaña nueva. Nada se clasifica por adivinanza.
